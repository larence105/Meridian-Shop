# Commerce Studio

A responsive storefront demo built with React. Product data comes from the public [Fake Store API](https://fakestoreapi.com/).

## Quick start

```bash
npm install
npm start
```

Runs the app at [http://localhost:3000](http://localhost:3000). Production bundle: `npm run build`.

## Stack

React 18, Redux, React Router, Bootstrap 5, Font Awesome — data via Fake Store API.
